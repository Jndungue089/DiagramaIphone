# Diagrama do iPhone

Exercício **Java** (DIO): implementação, em POO, do diagrama de classes de um iPhone com três funções.

| Função | Operações |
|---|---|
| Reprodutor musical | tocar, pausar, selecionar música |
| Aparelho telefónico | ligar, iniciar correio de voz, enviar mensagem |
| Navegador na Internet | exibir página, adicionar nova aba, atualizar página |

```bash
javac src/App.java
java -cp src App
```
